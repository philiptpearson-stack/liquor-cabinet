# Crayon art sources

The scene SVGs in `src/pages/**/scenes/` are generated by these scripts. Edit here, then regenerate.

- `art.py`: the cast (Bill, Margie, the everyman, posh lady...) and drawing helpers (wash, crayon lines, limbs, faces).
- `scenes.py`: The Founder's Gamble scenes, the Maker's cast icons, and the kit's generic door icons.
- `margie_scenes.py`: Margie Samuels's scenes.
- `sheet.py` / `msheet.py`: contact sheets of scenes at chosen animation times, for checking motion frames.

Run from this folder: `python3 scenes.py`, `python3 margie_scenes.py`. Contact sheets: `python3 sheet.py hello,pour 1000,3000 out/sheet.png` (needs `out/`).
