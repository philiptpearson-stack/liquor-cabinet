# Crayon art sources

The scene SVGs in `src/pages/**/scenes/` are generated by these scripts. Edit here, then regenerate.

- `art.py`: the cast (Bill, Margie, the everyman, posh lady...) and drawing helpers (wash, crayon lines, limbs, faces).
  **House rule: crowds look like the world they're in.** Inclusive, not heavy-handed: `everyman(**variety(i))` gives the
  i-th person in a crowd a natural mix of skin tone (`SKINS`), hair (cap, fedora, hair, curls, long, bun, bald; colors in
  `HAIRS`) and sometimes glasses, never matching the person next to them. Fit the era and the place.
- `bartender.py`, `bartender_scenes.py`: Phil the bartender, and The Bartender's Perspective scenes (they write that page's CSS too).
- `front_scenes.py`: The Bar, the app's front page: Phil waving hello, the door icons, and that page's CSS.
- `howto_scenes.py`: Cocktails How-To: the hub's icons and hero, and The Golden Ratio's scenes (they write those pages' CSS too).
- `stirred_scenes.py`: Cocktails How-To / Stirred Drinks: its three scenes and CSS, and the six drink doors it copies from the menu's cast (rerun after menu_pages.py changes an icon).
- The Cocktail Menu, in three parts. `menu_drinks.py`: every drink's recipe, words and build steps (the one file to edit for a recipe or a line).
  `menu_art.py`: glasses, garnishes, generic labeled bottles, fruit. `menu_build.py`: turns a drink's list of steps (pour, dash, egg, ice,
  shake, stir, strain, top, float, sink, garnish) into an animated build scene. `menu_pages.py` writes every menu page (story, copy, CSS, scenes);
  drinks Philip has hand-edited come out of its `REWRITE` set so they aren't overwritten.
- `scenes.py`: The Founder's Gamble scenes, the Maker's cast icons, and the kit's generic door icons.
- `margie_scenes.py`: Margie Samuels's scenes.
- `wsj_scenes.py`: the WSJ article's scenes.
- `shelves.py`: the liquor store shelves, shared by The Founder's Gamble and the WSJ page.
- `sheet.py` / `msheet.py` / `wsheet.py`: contact sheets of scenes at chosen animation times, for checking motion frames.

Run from this folder: `python3 scenes.py`, `python3 margie_scenes.py`. Contact sheets: `python3 sheet.py hello,pour 1000,3000 out/sheet.png` (needs `out/`).
